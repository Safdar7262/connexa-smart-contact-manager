About Smart Contact Manager

Smart Contact Manager (SCM) is a modern web application designed to help you efficiently store, manage, and organize your contacts in a secure and user-friendly way.

Why SCM?

Managing contacts can be messy when scattered across devices. SCM provides a centralized platform where you can easily access, update, and organize all your contacts.

Built with modern technologies like Spring Boot and Thymeleaf, this application ensures performance, scalability, and security.

Key Highlights

  • ✔ Secure authentication system
  • ✔ Easy contact management
  • ✔ Fast search & filtering
  • ✔ Responsive design
  • ✔ Clean and modern UI
